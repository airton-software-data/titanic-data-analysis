# Titanic Data Analysis

## 📌 Objetivo
Este projeto realiza uma análise exploratória do dataset Titanic, buscando entender fatores que influenciaram na sobrevivência dos passageiros.

## 🛠️ Tecnologias
- Python
- Pandas
- Matplotlib
- Seaborn

## 📂 Estrutura
- `data/`: dataset utilizado
- `notebooks/`: análises exploratórias em Jupyter Notebook
- `src/`: scripts auxiliares
- `README.md`: documentação

## 🚀 Resultados
- Mulheres tiveram maior taxa de sobrevivência.
- Passageiros mais jovens sobreviveram mais.
- Classe social influenciou fortemente a sobrevivência.
